# Маркеры ARKotlinReserve

- Словарь: `DICT_4X4_50`.
- ID: `7` и `23`.
- Измеряемый размер: внешняя сторона чёрного квадрата — `80 мм`; белое поле не входит в размер маркера.
- Для печати используйте `markers-print-a4-300dpi.png`, формат A4, 300 dpi.
- В диалоге печати выберите «Фактический размер» или 100%. Отключите «Подогнать к странице».
- После печати измерьте чёрный квадрат линейкой. Если он не равен 80 мм, не используйте лист для оценки позы.

Повторная генерация и проверка:

```powershell
python -m pip install --user opencv-contrib-python-headless==4.13.0.92
python .\tools\generate_markers.py
```

Скрипт повторно декодирует отдельные PNG и завершится ошибкой при несовпадении ID.
