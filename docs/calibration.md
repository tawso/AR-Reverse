# Калибровка

Профили находятся в `sample-app/src/main/assets/camera-calibration.json` и выбираются по Camera2 ID задней камеры.

```json
{
  "profiles": [{
    "cameraId": "0",
    "imageWidth": 1920,
    "imageHeight": 1080,
    "fx": 1420.1,
    "fy": 1418.7,
    "cx": 958.2,
    "cy": 541.6,
    "distortion": [-0.12, 0.04, 0.001, -0.002, 0.0]
  }]
}
```

Числа выше показывают только формат и не являются профилем какого-либо устройства. Текущий файл намеренно пуст: Nubia не калибровался.

Получайте параметры калибровкой выбранной физической камеры по серии снимков плоской шахматной доски/Charuco при фиксированном camera ID и известном размере клетки. Сохраняйте исходное разрешение профиля; toolkit масштабирует intrinsics к analysis resolution и преобразует их при rotation. Не переносите профиль между camera ID, режимами crop/binning или устройствами.

Если профиль отсутствует или JSON не читается, используется `fx = fy = max(width, height)`, главная точка в центре, нулевая дисторсия. Диагностика показывает «жуық». Детекция работает, но режим не предназначен для измерений или заявления о точности привязки.
